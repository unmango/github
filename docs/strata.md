# strata

Planned repo: `unmango/strata`.

## Description

It is a nix-first tool for developer environments similar to devenv or mise.
It provides an opinionated way to develop software.
A repo starts from a common base template and layers any number of patches on top of the template.
These layers are where development occurs.
It intends to integrate with patchpad for editing layers.
Git and version control are a first-class citizen.

## Name

Geological strata: layers deposited over a base.
One layer is a `stratum`, which gives the CLI its vocabulary.
