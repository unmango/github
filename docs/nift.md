# nift

Planned repo: `unmango/nift`.

## Description

Nix flake templates are a glorified copy-paste: `nix flake init -t` copies a directory and stops there.
nift adds real templating on top of them.
The core feature is variable replacement, so a template can be parameterized instead of hand-edited after the copy.
It builds on flake templates rather than replacing them, so an existing template stays a valid flake template.

## Name

Initialism for nix flake templates.
Short, pronounceable, and unclaimed.
